# 모니터링 설정 가이드

## 개요

이 디렉토리는 **로컬 개발 환경 전용** 모니터링 설정입니다.

## 로컬 개발 환경 설정

### 네트워크 구조
- **네트워크 타입**: bridge 네트워크
- **서비스 간 통신**: 컨테이너명 기반 통신
  - 예: `main:8000` (main 애플리케이션)
  - 예: `loki:3100` (Loki 로그 수집기)
  - 예: `prometheus:9090` (Prometheus 메트릭)

### 사용 예시
```bash
docker-compose -f docker-compose.monitoring.yml up -d
```

## 프로덕션 환경 설정

프로덕션 모니터링 설정은 **별도 저장소**의 `depoly` 구조를 따릅니다.

### 위치
```
{depoly-repo}/config/monitoring/
```

### 프로덕션 환경의 특징
- **네트워크 타입**: host 네트워크
- **설정 방식**: IP 변수 기반 `envsubst` 템플릿 사용
- 로컬 개발과는 완전히 다른 구조

## 주의사항

### 이미지 버전 동기화
로컬과 프로덕션 환경의 다음 이미지 태그가 **일치**하는지 확인하세요:

- `prometheus` 버전
- `grafana` 버전
- `loki` 버전
- 기타 모니터링 도구 버전

**버전 불일치 시 발생 가능한 문제:**
- 메트릭 형식 호환성 문제
- 대시보드 쿼리 오류
- 로그 수집 실패

## 참고

- 로컬 개발 시 변경사항은 이 디렉토리에서만 수정
- 프로덕션 배포는 `depoly` 저장소의 `config/monitoring/`을 참조
